# 鈴音新聞整理室

A lightweight static news digest room generated by a Hermes local news pipeline.

公開頁面（GitHub Pages）：

- <https://suzune-maid.github.io/suzune-news-room/>

## What this repo contains

- `index.html` — the GitHub Pages shell UI.
- `data/manifest.json` — available dates and category metadata.
- `data/YYYY-MM-DD.json` — per-day payloads loaded lazily by the browser.
- `scripts/` — Python stdlib-only pipeline scripts for RSS collection, freshness checks, digest input preparation, and static-site build.
- `config/news_sources.json` — RSS source configuration.

## Architecture

The deployed page uses the long-term P0 structure:

```text
index.html
  ↓ fetch()
data/manifest.json
  ↓ fetch selected date only
data/YYYY-MM-DD.json
```

This avoids embedding all historical news data into one ever-growing HTML file.

## Local preview

```bash
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

Direct `file://` opening may fail because the page uses `fetch()` to load JSON.

## Pipeline scripts

All scripts use Python standard library only.

```bash
# Collect one category into archive/news/daily/<date>/
python3 scripts/news_collect_category.py taiwan

# Check whether today's collection is usable
python3 scripts/news_check_freshness.py --date $(TZ=Asia/Taipei date +%F)

# Prepare compact LLM input
python3 scripts/news_prepare_digest_input.py --date $(TZ=Asia/Taipei date +%F)

# Build/refresh the static site root and data files
python3 scripts/news_build_static_site.py
```

## Deployment note

This repository is intentionally static. The current public page reflects the latest generated `index.html` and `data/*.json` committed to `main`.

After the local Hermes pipeline rebuilds `/home/atmjin/.hermes/archive/news/site`, publish the refreshed static assets with:

```bash
python3 scripts/publish_site.py \
  --source /home/atmjin/.hermes/archive/news/site \
  --repo /home/atmjin/.hermes/archive/github/suzune-news-room
```

The publish script stages only `index.html` and `data/*.json`, commits if there are changes, and pushes `main` for GitHub Pages.

Future automation can move collection/building into GitHub Actions if the RSS pipeline is later made cloud-hosted.

## Privacy note

The deployed `data/*.json` files contain RSS-derived titles, summaries, source names, URLs, and generated digest text. Do not commit private notes, credentials, Hermes session logs, or local runtime state.
